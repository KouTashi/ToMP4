# ToMP4

フォルダ内の動画をまとめて MP4 に変換する Python スクリプトです。画質をできるだけ落とさないことを優先しています。

- 変換した動画は `output/` に保存します
- 変換に成功した元の動画は `input/` に移動します（失敗した動画は元の場所に残ります）

## 必要なもの

- Python 3.10 以上
- ffmpeg（次のどちらか）
  - **ffmpeg 本体**: インストールして PATH に追加する
  - **imageio-ffmpeg**: `pip install imageio-ffmpeg`

PATH 上の ffmpeg を優先して使い、見つからなければ imageio-ffmpeg に同梱の ffmpeg を使います。

## 使い方

```
python to_mp4.py                 # to_mp4.py があるフォルダを処理
python to_mp4.py D:\videos       # 指定したフォルダを処理
python to_mp4.py D:\videos -r    # サブフォルダの中も処理
```

実行後のフォルダ構成の例:

```
videos/
├── input/       元の動画（変換に成功したもの）
│   ├── a.avi
│   └── b.mov
└── output/      変換後の MP4
    ├── a.mp4
    └── b.mp4
```

## 画質について

1. **そのまま詰め替え（無劣化）**: 映像や音声が MP4 で使える形式（H.264 / HEVC / AV1、AAC / MP3 など）なら、再エンコードせずに MP4 に入れ替えます。画質は一切落ちず、処理も一瞬です。iPhone で撮った動画（HEVC、HDR）もこの方法で変換されます。
2. **再エンコード**: MP4 で使えない形式の場合は、H.264（CRF 18、preset slow）と AAC（320kbps）に変換します。見た目ではほぼ劣化が分からない設定です。
   - 縦横が奇数ピクセルの動画は、拡大・縮小せずに 1px の余白を足して偶数に揃えます。

ffmpeg で読めない音声トラック（iPhone の空間オーディオなど）は除外します。通常のステレオ音声は残ります。

## オプション

| オプション | 説明 |
| --- | --- |
| `-r`, `--recursive` | サブフォルダの中の動画も処理する |
| `-y`, `--overwrite` | `output` 内の同名ファイルを上書きする（既定は `a (1).mp4` のように番号を付けて保存） |
| `--reencode` | 詰め替えられる形式でも必ず H.264 に再エンコードする（古い機器との互換性を優先したいとき） |
| `--crf N` | 再エンコード時の画質（0〜51、小さいほど高画質。既定 18） |
| `--preset NAME` | 再エンコードの速度（ultrafast〜veryslow。遅いほど同じサイズで高画質。既定 slow） |
| `--audio-bitrate RATE` | 音声を再エンコードするときのビットレート（既定 320k） |
| `--lossless` | 映像を完全無劣化で再エンコードする（ファイルが大きくなり、再生できない機器もある） |

## 対応している入力形式

`.avi` `.mkv` `.mov` `.wmv` `.flv` `.webm` `.m4v` `.mpg` `.mpeg` `.3gp` `.3g2` `.ts` `.mts` `.m2ts` `.vob` `.ogv` `.asf` `.rm` `.rmvb` `.divx` `.f4v` `.mxf` `.mp4`

## 注意

- **HEVC の再生**: iPhone の動画などを詰め替えた MP4 は、映像が HEVC のままです。Windows 標準のアプリで映像が出ない場合は、Microsoft Store の「HEVC ビデオ拡張機能」を入れるか、VLC などのプレーヤーを使ってください。どの機器でも再生できるようにしたい場合は `--reencode` を付けて実行してください。
- **10bit や HDR の動画を再エンコードする場合**: 互換性を優先して 8bit に変換するので、色の情報が少し落ちます。色まで完全に残したい場合は `--lossless` を使ってください。
